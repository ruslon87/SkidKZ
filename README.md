# SkidKZ
SkidKZ
SkidKZ

SkidKZ — Flutter-приложение маркетплейс-типа с системой промокодов и распределением маржи между участниками сделки.

Основная логика

Модель работы:

Товар → Маржа → Промокод → Заказ → Распределение прибыли

Пользователь может просматривать витрину без авторизации

При оформлении используется промокод

Заказ сохраняет snapshot товара (цена, маржа, проценты)

Расчёт прибыли остаётся корректным даже при изменении товара в будущем

Архитектура

Flutter

Riverpod

GoRouter

Firebase (Auth + Firestore)

Роли

Buyer — покупатель

Seller — продавец

Wanghong — инфлюенсер (получает % от маржи по промокоду)

Проект находится в активной разработке.
